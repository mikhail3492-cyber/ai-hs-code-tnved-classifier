# AI HS Code & TN VED Classifier — определение кода ТН ВЭД ЕАЭС

Практический AI-инструмент для **предварительной классификации товаров по HS Code и ТН ВЭД ЕАЭС** с использованием ChatGPT и Excel.

На основании характеристик и фотографий товара выполняется подбор кода ТН ВЭД, анализ ввозных пошлин, НДС, разрешительной документации и возможных альтернативных кодов.

**Результат:** заполненный Excel-файл с сохранением исходного оформления и профессиональный аналитический бриф в формате Word.

## Возможности

- Определение HS Code и наиболее обоснованного кода ТН ВЭД ЕАЭС.
- Анализ характеристик товара и фотографий.
- Проверка ставок пошлин, НДС и дополнительных таможенных мер.
- Определение требований к декларированию соответствия, сертификации, СГР и лицензированию.
- Анализ альтернативных кодов при наличии классификационных оснований.
- Формирование готового Excel и краткого профессионального брифа.

Инструмент предназначен для предварительной оценки импортных требований и может использоваться специалистами по закупкам, логистике и ВЭД.

## Файлы проекта

### Prompt

Содержит рабочую инструкцию для ChatGPT:

**Промт_ОПРЕДЕЛЕНИЕ КОДА ТН ВЭД ЕАЭС — HS COD.docx**

Инструкция определяет методику классификации, порядок проверки источников, заполнения Excel, сохранения его структуры и формирования итогового заключения.

### Input

Исходные материалы для запуска:

- **HS_Code_found_by_ChatGPT.xlsx** — Excel-шаблон с характеристиками товара.
- **Photo№1.jpg, Photo№2.jpg, Photo№3.jpg** — дополнительные фотографии товара.

### Results

Пример результата обработки искусственных пальмовых листьев:

- **HS_Code_found_by_ChatGPT_Artificial palm tree leaves.xlsx** — заполненная таблица с кодами, ставками и разрешительными требованиями.
- **Краткий_бриф_ТНВЭД_Artificial palm tree leaves.docx** — аналитическое заключение с обоснованием классификации и комментариями.

## Как начать работу

1. **Настройте ветку ChatGPT.** Создайте отдельный чат или проект. Загрузите инструкцию из папки **Prompt**, затем Excel-шаблон и фотографии из папки **Input**.
2. **Получите результат.** ChatGPT анализирует товар, проверяет доступные нормативные источники и формирует заполненный Excel, Word-бриф и краткие комментарии непосредственно в чате.
3. **Проверьте результат.** Сравните сформированные файлы с образцами из папки **Results**.

## Как использовать для другого товара

Заполните **HS_Code_found_by_ChatGPT.xlsx** характеристиками нового товара, сохранив исходную структуру таблицы.

Загрузите файл в ранее настроенную ветку ChatGPT. При необходимости добавьте фотографии, техническое описание или спецификацию.

ChatGPT проведёт новый анализ и сформирует Excel с названием товара на английском языке, а также краткий профессиональный бриф.

Повторно загружать промпт не требуется, если инструкция и исходный шаблон остаются доступны в ветке.

Для работы необходимы возможности обработки Excel-файлов и актуального веб-поиска.

## Основные правила и ограничения

- Классификация выполняется по имеющимся характеристикам товара с применением ОПИ ТН ВЭД ЕАЭС и доступных нормативных источников.
- Неполные исходные данные допускаются, однако могут влиять на точность классификации.
- Альтернативные коды рассматриваются только при наличии обоснованных оснований.
- Ставки пошлин, НДС и разрешительные требования должны проверяться на актуальность.
- Исходная структура Excel, объединённые ячейки, размеры, границы, шрифты и оформление сохраняются.

**Результат носит предварительный аналитический характер.** Он не является официальным классификационным решением таможенного органа.

Перед фактическим импортом рекомендуется подтвердить код ТН ВЭД, применимые платежи и разрешительные требования у таможенного представителя или уполномоченного органа.
