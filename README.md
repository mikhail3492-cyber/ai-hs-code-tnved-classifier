# ai-hs-code-tnved-classifier
Практический AI-инструмент для предварительного определения HS Code и кода ТН ВЭД ЕАЭС. Проверяет ставки пошлин, НДС, разрешительную документацию и возможные альтернативные коды. Использует ChatGPT и Excel. Не является официальной методикой классификации или продуктом OpenAI.
